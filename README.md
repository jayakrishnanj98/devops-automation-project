# DevOps Automation Project

## Project Overview

An end-to-end DevOps automation project designed to automate infrastructure provisioning, server configuration, application deployment, container orchestration, and monitoring using AWS and industry-standard DevOps tools.

## Technologies Used

- AWS EC2
- Terraform
- Ansible
- Jenkins
- Git and GitHub
- Docker
- Kubernetes
- GitHub Actions
- Prometheus
- Grafana
